# Inzpo

A single-user web app for collecting, organizing, and rediscovering design
inspiration — URLs, screenshots, photos, color palettes, articles, and videos —
with a faceted ontology (style, usage, medium, format, …) that powers advanced
filtering and grouping.

The core value: **finding that thing you saved again** — filter by style ×
usage × medium × palette, in a space that stays fast and beautiful as the
library grows.
