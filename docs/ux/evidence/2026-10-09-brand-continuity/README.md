# Brand continuity material studies

These images are **static browser translations of shipping native component
props, content and styles**, not screenshots from Expo Go or an iPhone.
A temporary Jest fixture rendered the actual component trees using the
project's native mocks, flattened their styles, and serialized them into HTML.
The renderer used the local Akaya Kanadaka/Geist fonts and existing texture
assets. A resting approved mascot image substituted for Skia where needed.

The sample kit data are fixtures. The bundled sample photo and fixture palette
are not a claim of extraction accuracy or a real saved user kit.

- `editor-375.jpg`, `editor-390.jpg`: selected role, readable cream labels,
  framed light paint, working preview and anchored Save/Cancel.
- `reuse-375.jpg`, `reuse-390.jpg`: actual supplied thumbnail/title, named
  stock swatches and reuse actions.
- `folders-375.jpg`: normal and long collection names with real fixture counts.
- `notes-375.jpg`: ready, pending and failed treatments for the same component.

Native text layout, keyboard, font scaling, scrolling, dragging, accessibility
and frame rate remain device checks. Source review separately corrected count
tab flow and Baku/Edit spacing. The temporary fixture, local server and browser
tab were removed; no preview runtime is part of the application.
